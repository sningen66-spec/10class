Как переводить числа

В восьмеричной системе 8 цифр (0–7), в шестнадцатеричной — 16: цифры 0–9 и буквы A–F (A = 10, B = 11, C = 12, D = 13, E = 14, F = 15). Число 8 равно 2³, а 16 равно 2⁴, поэтому перевод между этими системами и двоичной делается без вычислений — по таблице.

Двоичная → восьмеричная. Разбейте число справа налево на группы по 3 цифры (триады). Если в левой группе не хватает цифр, допишите нули слева. Замените каждую триаду одной восьмеричной цифрой.
Двоичная → шестнадцатеричная. То же самое, но группы по 4 цифры (тетрады).
Восьмеричная / шестнадцатеричная → двоичная. Замените каждую цифру её двоичной записью: тремя цифрами для восьмеричной, четырьмя для шестнадцатеричной. Ведущие нули результата отбросьте.
Восьмеричная ↔ шестнадцатеричная. Переведите число в двоичную систему, а затем из двоичной в нужную.
10110102 → 001 011 010 → 1 3 2 → 1328
10110102 → 0101 1010 → 5 A → 5A16
7C16 → 0111 1100 → 11111002

    Практика с подсказками

      Контрольная работа

      10 заданий на перевод между системами 2, 8 и 16. Подсказок нет, результат вы увидите в конце. Ответ можно писать без указания системы; буквы A–F — любым регистром.

      Оценка: 90% и выше — «5», 75% — «4», 50% — «3», ниже — «2».
